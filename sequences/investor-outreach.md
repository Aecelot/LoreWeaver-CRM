I'm Rijk, co-founder of LoreWeaver. We're building AI-native tools for narrative production in games.

**The problem:** Narrative-heavy games (RPGs, adventure, visual novels) burn 30-40% of production time on "narrative ops" — structuring content, managing branches, keeping versions in sync. And once shipped, the narrative is static — NPCs can't adapt, stories can't respond to player choices in real-time.

**What we built:**

- **Architect** (live, paying customers) — production tool that turns lore docs + notes into game-ready narrative structures in seconds. Not AI-generated writing — AI-structured production.
- **Director** (alpha, Q2 2027) — on-device narrative runtime. Dynamic NPC behavior, conflict resolution, adaptive story arcs — all running locally. No cloud dependency, fixed licensing, zero latency.

**Why we're different:**

Inworld, Convai, Ubisoft NEO NPC — all cloud-dependent. We're betting on on-device inference. Studios get predictable costs, offline capability, player data stays local, no platform holder pushback.
